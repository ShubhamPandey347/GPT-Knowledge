# Problems & Issues

This directory is the persistent troubleshooting and problem-solving knowledge base.

## Purpose

Record important problems encountered across systems, projects, software, hardware, deployments, workflows, and integrations so that future troubleshooting can start from known symptoms, causes, attempted fixes, and verified solutions.

## Recommended Record Structure

Each significant problem should capture:

- **Problem:** concise description
- **Context:** system/project/environment
- **Symptoms:** observable behavior and exact errors
- **Likely Cause:** hypotheses and confidence
- **Investigation:** tests performed and results
- **Attempts:** fixes tried, including failures
- **Solution:** verified fix, if known
- **Workaround:** temporary mitigation, if applicable
- **Status:** Open / Investigating / Blocked / Resolved / Monitoring
- **Impact:** Low / Medium / High / Critical
- **Related:** links to projects, systems, decisions, or other problems
- **Last Verified:** date of last verification

## Organization

Use topic-specific files or subdirectories when the number of records grows. Prefer descriptive names such as:

- `windows-wifi-bluetooth.md`
- `ubuntu-audio.md`
- `openclaw-gateway.md`
- `vercel-deployment.md`
- `ollama-lm-studio.md`

Do not store secrets, credentials, API keys, tokens, personal identifiers, or other sensitive information here.
